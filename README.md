A short poem about agency — the power to choose and to act — written as a program (main.py) that writes the poem to entry.txt. The poem follows a person who lends their hands to an AI agent, keeps the choosing for themselves, and learns what the doing costs when it is lent away.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
